LR PELUQUERÍA — DEMO INTERACTIVA PARA ANDROID

Incluye una demo navegable con:
- Inicio, servicios y precios de ejemplo
- Reserva de turnos con selección de servicio, fecha y horario
- Cursos de colorimetría con formulario de inscripción
- Galería, promociones, cuenta, mis turnos y contacto
- Panel administrativo de muestra
- Compilación automática de APK mediante GitHub Actions

IMPORTANTE:
Esta es una DEMO: los turnos y las inscripciones se guardan localmente en el dispositivo/navegador.
No hay sincronización entre teléfonos, pagos reales ni notificaciones automáticas.
Los precios, profesionales, horarios y datos de contacto son de ejemplo y deben reemplazarse.

CÓMO OBTENER EL APK:
1. Descomprimí este ZIP.
2. Subí el contenido a un repositorio nuevo de GitHub.
3. Entrá a la pestaña Actions y habilitá los workflows si GitHub lo solicita.
4. Ejecutá el workflow "Compilar APK LR Peluquería" con Run workflow.
5. Cuando termine, abrí la ejecución y descargá el artefacto "LR-Peluqueria-APK".
6. Descomprimí el artefacto y abrí app-debug.apk en tu Android para instalarlo.
